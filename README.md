# 语音真伪鉴别 · Voice Guard

判断一段语音是**真人录音**还是 **AI 合成**，支持上传音频和**浏览器在线录音**，
并可视化展示逐段「疑似合成度」。

## 原理（双模型）

| 模型 | 作用 | 说明 |
|---|---|---|
| 深度模型 | 主结论（真人 / AI合成） | `mo-thecreator/Deepfake-audio-detection`，wav2vec2-base 在 ASVspoof 数据上微调的真伪二分类器，约 360MB，CPU 推理 |
| 轻量模型 | 离线兜底 + 变声提示 + 分段曲线 | 本地 SVC 三分类（真人/AI合成/变声），56 维声学特征，秒级出结果 |

- 深度模型可用时：主结论取深度模型；轻量模型若检出变声痕迹（P>0.5）会附加提示。
- 深度模型未下载/失败时：自动降级为纯轻量模型，页面明确标注「精度有限」。
- 深度模型未下载/失败时：主结论取轻量模型，页面明确标注「精度有限」。

## 快速开始

1. 安装 Python 3.9+（安装时勾选 `Add python.exe to PATH`）
2. 双击 `start.bat`
   - 首次运行自动创建 `.venv` 并安装依赖（含 PyTorch CPU ~200MB，3–15 分钟）
   - 装好后自动打开 http://127.0.0.1:8000
3. 页面右上角状态条点「下载」获取深度模型（约 360MB，经 hf-mirror 国内镜像，仅首次；
   下载器自动分块并行 + 断点续传，慢网约 30-60 分钟，可随时重试）
   - 不下载也能用：轻量模型 + 样例按钮立即可测
4. 拖入音频 / 点样例按钮 / 点「开始录音」在线鉴别

## 在线录音

- 点「开始录音」，浏览器请求麦克风权限（首次需允许）
- 最长 60 秒自动停止；停止后可试听，再点「用这段音频鉴别」
- 录音中实时显示**输入音量条**——音量条不动说明麦克风没录到音
- 支持**输入设备选择**：权限授予后出现「输入设备」下拉框，
  录音没声音时优先换设备（常见原因：默认设备选成了"立体声混音"/显示器音频）
- 录音在浏览器本地编码为 WAV（16kHz 单声道）上传本机服务分析，不经过任何第三方服务器

## 支持格式

wav / mp3 / flac / ogg / **m4a / aac**（m4a 等压缩格式由内置 ffmpeg 库 PyAV 解码，
无需安装 ffmpeg 软件）

## 结果解读

- **判定徽章**：真人（绿）/ AI合成（橙）/ 变声（红），附置信度
- **概率条**：深度模型二分概率 + 轻量模型三分概率
- **波形图**：红色面积 = 轻量模型滑窗（2s 窗 / 0.5s 步）打出的逐段疑似合成度；
  绿色虚线 = 深度模型的分块边界（≤30s 音频等分 ≤3 块）
- **频谱图**：log-mel 频谱
- 结论仅供参考，不构成法律或安全结论

## 常见问题

**Q: torch 装不上？**
start.bat 依次尝试阿里云镜像 → 上交 SJTU pytorch 镜像 → 官方 CPU 源，都失败只会警告（轻量模型照常）。
之后可手动重试：
`.venv\Scripts\python.exe -m pip install torch==2.8.0 --no-deps -i https://mirrors.aliyun.com/pypi/simple/`
（实测阿里云 724KB/s；官方 pytorch 源在本网络会卡死，勿用）

**Q: 深度模型下载失败？**
状态条会显示「不可用（可重试）」。也可以手动放置：
把 `config.json`、`preprocessor_config.json`、`model.safetensors`
（来自 hf-mirror.com/mo-thecreator/Deepfake-audio-detection）放进 `models\deepfake_audio\` 即可，
应用启动时本地探测到文件即「就绪」，无需联网。

**Q: 分析很慢？**
深度模型在 CPU 上推理 30s 音频约需 10~60 秒，页面有进度提示。想快就上传更短的音频（≤10s 只跑 1 块）。
分段曲线由轻量模型绘制，不受影响。

**Q: 想禁用深度模型？**
改 `config.py` 里 `DEEP_ENABLED = False`，重启即纯轻量模式。

**Q: 结果能识别所有 AI 语音吗？**
不能保证。深度模型在 ASVspoof 基准上训练，对训练分布外的商用 TTS/变声器泛化有限；
轻量模型的变声判断同样仅供参考。重要场景请多方交叉验证。

## 文件说明

```
app.py             Flask 入口与路由
config.py          常量与开关（上限、模型路径、DEEP_ENABLED）
backend/           音频读取 / 特征提取 / 双模型 / 编排
templates/ static/ 网页界面（含录音、分段曲线）
samples/           三个内置样例（真人 / AI合成 / 变声）
models/            model.joblib（轻量模型）+ deepfake_audio/（深度模型，下载后）
tools/api_smoke.py 命令行冒烟测试脚本
start.bat          双击启动（自动装依赖 + 开服务）
```
